# 408-FLOW-1.2 — Direct-Start Routing

Status: Implemented

Explicit Start My Coverage Review actions now continue through the existing CoverageFit transition directly into the existing Home assessment. The shared launcher accepts declarative `data-cf-next`, while the Home Protection Score supplies the same `next=/assessment/` contract programmatically. Exploratory routes are intentionally unchanged. No second assessment or alternate transition was introduced.
